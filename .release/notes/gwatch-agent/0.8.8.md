# GWatch Agent 0.8.8

GWatch 0.8.12 and GWatch Agent 0.8.8 ship together.

## Fixed

- **Six-day certificates were always "expiring."** The certificate check the
  agent runs as a remote collector is the one GWatch runs: a certificate whose
  whole lifetime is shorter than the warning period now warns once a third of
  its lifetime is left, rather than from the day it was issued.
